## Rule C: conditional inference (separates fit agreement from inference-formula agreement)

For an accepted configuration and a coefficient whose robu-reference fit quantities (tau2, estimate, SE, df) ALL
pass at the unchanged strict thresholds, recompute the reference t, p, CI_lo and CI_hi in R 4.6.0 from the APP's
captured estimate, SE and df: t = est/se; p = 2*pt(-|t|, df); CI = est -/+ qt(0.975, df)*se. Compare the app's t,
p and CI with these at the unchanged strict thresholds. A coefficient passes Rule C only if all four match.
When any fit quantity fails, Rule C does not apply and the coefficient goes to Rule K or stays unexplained.

## Rule K: fit differences inside R's own reordering noise

For a fit quantity (tau2, estimate, SE, df) that fails strict: rerun robumeta::robu (same formula, CORR,
small=TRUE, same rho) on mathematically identical inputs under 8 reorderings: rows permuted within clusters
and cluster order permuted, with permutations drawn by `set.seed(20261018)` and recorded in r3-permutations.json
BEFORE the comparison runs. Let N_q = max over the 8 reorderings of |ref_perm - ref|. The quantity is
"explained by reference reordering noise" if |app - ref| <= N_q + strict_tol. Report N_q, |app - ref| and the
condition number kappa_1(X'WX) at the reference weights for every such quantity. This is a classification,
not a pass. No constant in this rule may be changed after seeing results.
