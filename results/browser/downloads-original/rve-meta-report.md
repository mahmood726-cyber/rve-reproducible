# Robust Variance Estimation (RVE)

_Generated 2026-10-19 with allmeta — browser-only evidence synthesis (https://github.com/)._

## Methods

Cluster-robust sandwich estimator for meta-regression with dependent effect sizes (multiple outcomes per study, multi-arm trials, repeated measures). Implements the Hedges-Tipton-Johnson 2010 correlated-effects (CORR) working model with a CR1 small-sample correction. The robustness is to misspecification of the within-cluster correlation ρ — it closes the inverse-variance underestimate that breaks fixed-effect / standard random-effects meta-regression when effects are nested. Coverage is good when the number of clusters is reasonably large; with few clusters (m≲20) the CR1 SEs are anticonservative — see the footer and use robumeta/clubSandwich (CR2) in R for inference there.

Engine: shared/rve.js — Hedges-Tipton-Johnson 2010 correlated-effects working model with the CR2 bias-reduced small-sample correction (Tipton 2015; Pustejovsky-Tipton 2018) and per-coefficient Satterthwaite degrees of freedom, the accurate default for inference with few clusters. τ² is the HTJ CORR moment estimator (not a plain DerSimonian-Laird across rows). t-quantiles via exact qt (Hill 1970). Calibration: matches robumeta::robu(modelweights="CORR", small=TRUE) on every reported quantity — τ², coefficients, CR2 SEs and Satterthwaite df — to ≤1e-5 (verified on homogeneous and heterogeneous datasets; see rve-meta-cr2-parity.spec.mjs). Because the CORR weights are constant within a cluster, the within-cluster annihilator block is symmetric, so Aj is a true symmetric inverse-square-root. CR1 (a single scalar correction, anticonservative at small m) remains available via fitCORR(rows,{method:"CR1"}). The HIER working model is not yet implemented; for hierarchical effects use robumeta::robu(model="HIER") in R.
